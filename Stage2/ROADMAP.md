## 🏆 The 5-Badge Curriculum Plan ("The Infrastructure & Security 5")

To qualify for the 100% discount exam voucher, you must complete **at least 5 of the 7 skill badges**, including the mandatory Gemini Enterprise badge. Each badge consists of guided labs followed by a timed, unguided **Challenge Lab**:

| # | Skill Badge Title | Status | Link | Core Exam Competencies Tested |
| :-: | :--- | :---: | :--- | :--- |
| **1** | **Create Your First Gemini Enterprise Application** | **MANDATORY** | [Link](https://www.skills.google/paths/3546/course_templates/1586) | Agent Runtime, Gemini Enterprise Agent Platform, Reasoning Engine, Cloud Run deployment. *(Cannot be skipped).* |
| **2** | **Implement Load Balancing on Compute Engine** | Required | [Link](https://www.skills.google/course_templates/648) | Managed Instance Groups (MIGs), HTTP(S) Load Balancer, SSL termination, Backend Services, Health Checks. |
| **3** | **Build Infrastructure with Terraform on Google Cloud** | Required | [Link](https://www.skills.google/course_templates/636) | HCL, Terraform state in Cloud Storage, modular VPC/VM deployment, `terraform plan/apply`. |
| **4** | **Build a Secure Google Cloud Network** | Required | [Link](https://www.skills.google/course_templates/654) | Custom VPCs, Bastion Host, Private Google Access, Firewall Priority & Target Tags, VPC Peering. |
| **5** | **Implement Cloud Security Fundamentals on Google Cloud** | Required | [Link](https://www.skills.google/course_templates/645) | IAM Least Privilege, Custom Roles, Service Account Keys vs impersonation, Cloud KMS (CMEK), Audit Logs. |

*Optional / Stretch Badges (if time permits post-voucher):*
* ★ [Set Up an App Dev Environment on Google Cloud](https://www.skills.google/course_templates/637)
* ★ [Develop your Google Cloud Network](https://www.skills.google/course_templates/625)

## 🏛️ Pearson VUE / CertMetrics Exam Registration Guide

1. **Portal:** [https://cp.certmetrics.com/google/en/login](https://cp.certmetrics.com/google/en/login)
2. **Account Name:** Must match your National ID or Passport character-for-character.
3. **Checking Dates in Advance (No Voucher Needed):**
   - Click **`Schedule/Launch an exam`** > Select **`Associate Cloud Engineer`** > Click **`SCHEDULE`**.
   - Choose **`At a local test center`** > Select English > Agree to policies.
   - Enter **`Cairo, Egypt`** in the search box.
   - Recommended test centers in Cairo:
     - **AMIDEAST Egypt** (38 Mohie El Din Abo El Ezz, Dokki / Giza)
     - **New Horizons** (Dokki / Nasr City)
     - **Synergy** (Dokki / Heliopolis)
   - Click Next to view open calendar dates and morning/afternoon times.
   - Close the browser tab before checkout to safely exit without booking.
4. **Booking with Voucher:**
   - Repeat the steps, proceed to the checkout screen, enter your voucher code, verify the charge is **USD $0.00**, and confirm your appointment.
